# 📖 Dicionário de Termos e Glossário Técnico

Este glossário padroniza todos os conceitos, siglas e termos técnicos utilizados em todo o ecossistema **Antigravity**.

---

## 📖 Dicionário de Termos (Glossário)

| Termo / Sigla | Definição Clara e Acessível |
| :--- | :--- |
| **Antigravity** | Ambiente de desenvolvimento de software agêntico da Google, projetado para pareamento autônomo com desenvolvedores humanos. |
| **API (Application Programming Interface)** | Conjunto de regras e protocolos que permite que sistemas distintos se comuniquem e troquem dados de forma padronizada. |
| **AST (Abstract Syntax Tree)** | Árvore sintática abstrata que representa a estrutura do código-fonte, utilizada por compiladores e revisores de código para análise estática. |
| **BaaS (Backend as a Service)** | Plataforma em nuvem (ex: Supabase, Firebase) que provê banco de dados, autenticação e armazenamento prontos para uso. |
| **Circuit Breaker** | Padrão arquitetural que interrompe loops repetitivos (ex: limite de 5 rodadas de bate-rebate entre subagente revisor e implementador). |
| **Core Web Vitals** | Conjunto de métricas padronizadas pelo Google (LCP, INP, CLS) para avaliar a velocidade, capacidade de resposta e estabilidade visual de páginas web. |
| **CORS (Cross-Origin Resource Sharing)** | Mecanismo de segurança dos navegadores que restringe quais domínios externos podem acessar recursos de uma API. |
| **DTO (Data Transfer Object)** | Objeto de transferência de dados tipado utilizado para serializar e validar entradas e saídas de dados, evitando exposição de modelos brutos de banco. |
| **DoD (Definition of Done)** | Critério observável e testável que define quando uma tarefa ou funcionalidade está verdadeiramente concluída e pronta para entrega. |
| **IDOR (Insecure Direct Object References)** | Vulnerabilidade de segurança em que um sistema expõe um objeto direto (como `/pedidos/123`) sem validar se o usuário autenticado é o dono do registro. |
| **KISS (Keep It Simple, Stupid)** | Princípio de engenharia que defende que sistemas funcionam melhor se forem mantidos simples e sem complexidade desnecessária. |
| **Ledger Persistente** | Arquivo em disco no formato append-only (`LEDGER_[PROJETO].md`) que registra o status das tarefas e sobrevive a compactações de contexto de IA. |
| **MCP (Model Context Protocol)** | Protocolo aberto criado para padronizar como modelos de linguagem acessam ferramentas externas, bancos de dados e APIs locais ou remotas. |
| **Ollama** | Ferramenta que permite executar modelos de linguagem (LLMs) open-source localmente na máquina sem depender de conexões com a internet. |
| **OWASP Top 10** | Lista internacional das dez vulnerabilidades de segurança mais críticas e comuns em aplicações web. |
| **PII (Personally Identifiable Information)** | Informações de identificação pessoal (como CPF, e-mail, telefone, endereço) sujeitas a leis de proteção de dados (LGPD/GDPR). |
| **RLS (Row Level Security)** | Mecanismo de segurança do PostgreSQL que restringe quais linhas de uma tabela um determinado usuário pode visualizar ou alterar. |
| **SDD (Spec-Driven Development)** | Metodologia onde a especificação detalhada de requisitos e arquitetura é criada e aprovada antes de qualquer linha de código de produção. |
| **SSRF (Server-Side Request Forgery)** | Vulnerabilidade onde um invasor induz um servidor a disparar requisições maliciosas contra sistemas internos ou redes privadas restritas. |
| **TDD (Test-Driven Development)** | Prática de desenvolvimento onde testes automatizados que falham (*Red*) são escritos antes do código de produção (*Green*), seguido por refatoração (*Refactor*). |
| **Wikilinks** | Formato de links bidirecionais utilizado no Obsidian no padrão `[[Nome da Nota]]` para conectar conceitos e formar grafos de conhecimento. |
| **YAGNI (You Aren't Gonna Need It)** | Princípio do Extreme Programming que orienta não adicionar funcionalidades até que elas sejam estritamente necessárias no momento atual. |
