# ⚡ Guia Completo de Comandos de Barra (Slash Commands)

O ecossistema **Antigravity** dispõe de atalhos em linguagem natural para acelerar comportamentos complexos de engenharia e orquestração agêntica:

---

## 🎯 Comandos de Ciclo de Vida do Software

| Comando | Descrição | Skills Acionadas |
| :--- | :--- | :--- |
| **`/spec`** | Define o que construir através de um PRD e mapa de capacidades antes de qualquer código. | `spec-driven-development`, `interview-me` |
| **`/plan`** | Elabora a decomposição técnica ordenada em fatias atômicas e ondas paralelas. | `planning-and-task-breakdown`, `vibe-architect` |
| **`/build`** | Implementa uma fatia fina de funcionalidade por vez com cobertura de testes. | `incremental-implementation`, `test-driven-development` |
| **`/build auto`**| Executa todas as fatias de um plano aprovado de forma autônoma sem pausas intermediárias. | `incremental-implementation`, `test-driven-development` |
| **`/test`** | Prova que o código funciona através de testes automatizados e suítes de regressão. | `test-driven-development`, `debugging-and-error-recovery` |
| **`/constraints`**| Define ou audita o contrato de qualidade inegociável do projeto (`CONSTRAINTS.md`). | `constraint-driven-development` |
| **`/review`** ou **`/verificar`** | Executa a auditoria final sob os 4 eixos (Qualidade, Segurança, Simplicidade e DoD). | `code-review-and-quality`, `security-and-hardening` |
| **`/webperf`** | Audita Core Web Vitals, tempo de carregamento e renderização em navegadores reais. | `performance-optimization`, `browser-testing-with-devtools` |
| **`/code-simplify`** | Refatora o código para eliminar complexidade acidental preservando o comportamento. | `code-simplification` |
| **`/ship`** | Prepara o checklist de lançamento, validações pré-deploy e planos de contingência/rollback. | `shipping-and-launch`, `ci-cd-and-automation` |

---

## 🧠 Comandos de Inteligência e Segundo Cérebro

| Comando | Descrição |
| :--- | :--- |
| **`/grill-me`** | Inicia a sabatina socrática profunda (uma pergunta por vez até 95% de clareza). |
| **`/ingerir`** | Processa um arquivo bruto de `RAW/` e gera notas atômicas interligadas em `WIKI/`. |
| **`/looping`** | Inicia o processamento contínuo em lote da fila `RAW/` até esvaziar a pasta. |
| **`/goal`** | Executa uma tarefa extensa de forma contínua até o objetivo ser atingido com rigor total. |
| **`/boost`** | Ativa reflexão profunda e múltiplos ângulos para problemas técnicos de altíssima complexidade. |
| **`/learn`** | Registra um aprendizado ou correção do usuário para persistência em tarefas futuras. |
