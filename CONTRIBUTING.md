# 🤝 Como Contribuir para o ANTIGRAVITY-SKILL-SUPREME

Agradecemos imensamente o seu interesse em contribuir! Este projeto visa ser o ecossistema definitivo e livre para desenvolvedores que utilizam o Google Antigravity e agentes de IA avançados.

---

## 🌟 Como Você Pode Ajudar

1. **Deixando uma Estrela (Star):** Se este projeto te economizou horas de trabalho, nos ajude deixando uma estrela no topo da página do GitHub! ⭐
2. **Criando Novas Skills:** Empacote suas melhores práticas em um diretório com `SKILL.md` claro e documentado.
3. **Aprimorando Regras e Workflows:** Sugira melhorias na economia de tokens, segurança ou novos servidores MCP.
4. **Relatando Problemas (Issues):** Encontrou um bug em um script ou comando? Abra uma issue detalhada.

---

## 🛠️ Diretrizes de Submissão

* **Padrão de Qualidade:** Todas as contribuições de código devem respeitar os 4 eixos do Quality Gate (`SOLID`, `OWASP DevSecOps`, `KISS/Chesterton's Fence` e `Definition of Done`).
* **Segurança Estrita:** Nenhuma chave, credencial ou dado sensível pode ser adicionado em commits.
* **Idioma:** Documentações centrais mantidas em Português do Brasil com espelhamento para Inglês internacional.

---

## 🚀 Passos para Enviar um Pull Request

1. Faça um Fork do repositório.
2. Crie um branch para sua melhoria: `git checkout -b feature/minha-nova-skill`.
3. Faça commit das suas alterações: `git commit -m 'feat: adicionar skill X'`.
4. Envie para o branch remoto: `git push origin feature/minha-nova-skill`.
5. Abra um Pull Request e descreva o impacto da sua adição!
